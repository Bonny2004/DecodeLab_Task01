# DecodeLab_Task01

## Data Analytics Project 1 – Data Cleaning & Preparation

This repository contains **Project 1** from the DecodeLabs Industrial Training Kit focused on **Data Cleaning & Preparation**. The project demonstrates essential data analytics skills such as handling missing values, removing duplicate records, correcting inconsistent formats, and preparing raw datasets for analysis using **Excel** or **Python (Pandas)**.

### Key Objectives

* Identify and handle missing/null values
* Remove duplicate records
* Standardize date, text, and numeric formats
* Improve overall data integrity and quality

### Skills & Tools

* Data Cleaning
* Data Preparation
* Excel / Power Query
* Python & Pandas

### Project Goal

Build a clean and reliable dataset that can be used for future analytics, dashboards, or machine learning workflows.

### Learning Outcome

This project emphasizes that high-quality analysis starts with high-quality data and highlights the importance of reproducible, well-documented data cleaning processes.
